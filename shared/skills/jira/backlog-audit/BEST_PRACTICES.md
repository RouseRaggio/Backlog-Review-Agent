# Best Practices

---

# Objetivo

Definir las buenas prácticas utilizadas durante la auditoría de Backlogs.

---

# General

- Escribir títulos claros.
- Evitar lenguaje ambiguo.
- Mantener consistencia.
- Documentar reglas de negocio.
- Documentar riesgos.

---

# Stories

- Utilizar "Como... Quiero... Para..."
- Incluir criterios de aceptación.
- Mantener historias pequeñas.
- Asegurar que sean estimables.
- Aplicar el principio INVEST.

---

# Tasks

- Describir claramente el trabajo.
- Evitar tareas demasiado grandes.
- Definir responsable.
- Asociar a una Epic cuando aplique.

---

# Bugs

- Documentar pasos para reproducir.
- Adjuntar evidencia.
- Especificar ambiente.
- Definir severidad.

---

# Epics

- Definir objetivo.
- Definir alcance.
- Mantener coherencia entre las Stories.

---

# Sub-tasks

- Mantenerlas pequeñas.
- Asociarlas al Issue padre.
- Describir claramente el trabajo.

---

# Auditoría

- Todas las observaciones deben ser objetivas.
- Toda observación debe incluir una recomendación.
- No asumir información inexistente.
- Evitar interpretaciones subjetivas.
