# Bug Audit Standard

**Skill:** Backlog Audit

**Versión:** 1.0.0

**Tipo de Issue:** Bug

---

# Objetivo

Definir el estándar organizacional para auditar Bugs en Jira.

Todo Bug debe contener información suficiente para que pueda reproducirse, analizarse y corregirse.

---

# Información Obligatoria

## Identificador

Debe existir.

---

## Resumen

Debe describir claramente el problema.

---

## Descripción

Debe explicar el comportamiento observado.

---

# Severidad

Debe existir una severidad válida.

Ejemplos:

- Critical
- High
- Medium
- Low

---

# Prioridad

Debe existir una prioridad.

---

# Pasos para Reproducir

Debe indicar paso a paso cómo reproducir el problema.

---

# Resultado Esperado

Debe describir el comportamiento esperado.

---

# Resultado Actual

Debe describir el comportamiento observado.

---

# Evidencia

Cuando aplique deberá incluir:

- Capturas
- Videos
- Logs
- Archivos

---

# Ambiente

Cuando aplique deberá indicar:

- DEV
- QA
- UAT
- Producción

---

# Hallazgos

Detectar como mínimo:

- Bug sin pasos para reproducir.
- Bug sin severidad.
- Bug sin prioridad.
- Bug sin evidencia.
- Bug ambiguo.
- Bug duplicado.
- Bug sin resultado esperado.

---

# Definition of Ready

Un Bug estará listo cuando:

- Puede reproducirse.
- Tiene severidad.
- Tiene prioridad.
- Tiene evidencia.
- Tiene ambiente.
- Describe claramente el problema.

---

# Estado Final

- READY
- NEEDS REVIEW
- NEEDS REFINEMENT
- BLOCKED
