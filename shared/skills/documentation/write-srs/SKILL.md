# Skill: Write SRS

## Objetivo

Generar un Software Requirements Specification (SRS) de nivel empresarial siguiendo el estándar IEEE 29148.

## Cuándo utilizar esta Skill

Utiliza esta Skill cuando:

- Se vaya a iniciar un nuevo proyecto.
- Sea necesario documentar requisitos funcionales.
- Se necesite una especificación para un arquitecto.
- Se vaya a trabajar con Specification Driven Development.

## No utilizar cuando

- Se vaya a diseñar arquitectura.
- Se requiera documentación técnica.
- Se escriba código.

En esos casos utilizar:

- write-sdd
- architecture-design
- implementation

## Entradas

La Skill requiere como mínimo:

- Problema de negocio
- Objetivo del sistema
- Actores
- Alcance
- Restricciones
- Reglas de negocio conocidas

## Salidas

Debe generar un documento Markdown que contenga:

- Introducción
- Propósito
- Alcance
- Stakeholders
- Requisitos Funcionales
- Requisitos No Funcionales
- Reglas de Negocio
- Casos de Uso
- Riesgos
- Restricciones
- Glosario

## Criterios de Calidad

El documento debe:

- Evitar ambigüedades.
- Ser verificable.
- Ser consistente.
- Ser completo.
- No incluir implementación.
- No mencionar tecnologías.
