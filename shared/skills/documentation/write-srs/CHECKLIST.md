# SRS Checklist

Antes de finalizar el documento verificar:

- [ ] Existe un propósito claro.

- [ ] El problema de negocio está descrito.

- [ ] Se identificaron los Stakeholders.

- [ ] Existe un alcance definido.

- [ ] Hay restricciones.

- [ ] Existen supuestos.

- [ ] Todos los RF están numerados.

- [ ] Todos los RNF están numerados.

- [ ] No existen ambigüedades.

- [ ] No aparecen tecnologías.

- [ ] No aparece arquitectura.

- [ ] No aparece código.

- [ ] Los casos de uso están completos.

- [ ] Las reglas de negocio están documentadas.

- [ ] El glosario está completo.
